### Step-by-Step Explanation

**1. Total Good Widgets Produced in 8 Hours**

For each machine, calculate the total widgets produced and then subtract the defective ones.

- **Machine A:**
  - Production: \(120 \, \text{widgets/hour} \times 8 \, \text{hours} = 960 \, \text{widgets}\)
  - Defects: \(960 \times 0.025 = 24\)
  - Good: \(960 - 24 = 936\)

- **Machine B:**
  - Production: \(200 \times 8 = 1600\)
  - Defects: \(1600 \times 0.04 = 64\)
  - Good: \(1600 - 64 = 1536\)

- **Machine C:**
  - Production: \(85 \times 8 = 680\)
  - Defects: \(680 \times 0.012 = 8.16\) (rounded to 8)
  - Good: \(680 - 8 = 672\)

- **Total Good Widgets:** \(936 + 1536 + 672 = 3144\)

**2. Overall Defect Rate**

- **Total Produced:** \(960 + 1600 + 680 = 3240\)
- **Total Defective:** \(24 + 64 + 8 = 96\)
- **Defect Rate:** \(\frac{96}{3240} \approx 0.0296\) or \(2.96\%\)

**3. Maximizing Good Widgets with Two Machines**

Calculate the good production per hour for each pair:

- **A and B:** \(120 \times 0.975 + 200 \times 0.96 = 117 + 192 = 309\)
- **A and C:** \(120 \times 0.975 + 85 \times 0.988 = 117 + 83.98 = 200.98\)
- **B and C:** \(200 \times 0.96 + 85 \times 0.988 = 192 + 83.98 = 275.98\)

The highest is **A and B** with **309 good widgets per hour**.

### Python Code Verification

```python
# Machine data
machines = [
    {'name': 'A', 'rate': 120, 'defect': 0.025},
    {'name': 'B', 'rate': 200, 'defect': 0.04},
    {'name': 'C', 'rate': 85, 'defect': 0.012}
]

# Question 1: Total good widgets in 8 hours
total_good = 0
for machine in machines:
    total = machine['rate'] * 8
    good = total * (1 - machine['defect'])
    total_good += good

print(f"Total good widgets: {total_good:.0f}")

# Question 2: Overall defect rate
total_produced = sum(machine['rate'] * 8 for machine in machines)
total_defective = total_produced - total_good
defect_rate = (total_defective / total_produced) * 100
print(f"Overall defect rate: {defect_rate:.2f}%")

# Question 3: Best two machines
good_per_hour = {machine['name']: machine['rate'] * (1 - machine['defect']) for machine in machines}
pairs = [('A', 'B'), ('A', 'C'), ('B', 'C')]
max_good = 0
best_pair = ''

for pair in pairs:
    total = good_per_hour[pair[0]] + good_per_hour[pair[1]]
    if total > max_good:
        max_good = total
        best_pair = f"{pair[0]} and {pair[1]}"

print(f"Best pair: {best_pair} with {max_good:.0f} good widgets per hour.")
```
